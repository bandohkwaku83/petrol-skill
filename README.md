# PetroSkill Virtual Learning

Next.js marketing website for PetroSkill Virtual Learning (PVL) — a professional training institute for oil, gas, energy, and emerging technology.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Course and internship **Register Now** / waitlist buttons point to placeholder Microsoft Forms URLs in `src/data/content.ts` — replace with your real form links.
- Content (courses, news, partners, etc.) lives in `src/data/content.ts`.
- Images are loaded from Unsplash.
